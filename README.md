# Longhorn Chess - Non-Profit Chess Club Website

A professional, fully responsive static HTML website for the Longhorn Chess non-profit organization.

## 📋 Website Structure

The website includes the following sections:

- **Navigation** - Sticky navbar with smooth scrolling
- **Home** - Hero section with call-to-action
- **About** - Community overview and values
- **Mission** - Mission statement and objectives
- **Programs** - Four program offerings
- **Tournaments** - Tournament types and benefits
- **Why Chess** - Six key benefits of chess
- **Contact** - Contact information and form
- **Footer** - Copyright and organization info

## 🎨 Design Features

- **Color Scheme:** Deep Green, Gold, and Orange
- **Responsive Design:** Mobile-first approach
- **Animations:** Smooth transitions and fade-in effects
- **Accessibility:** Semantic HTML, keyboard navigation
- **Performance:** Fast loading, no external dependencies

## 📱 Responsive Breakpoints

- Desktop: 1200px and above
- Tablet: 768px to 1199px
- Mobile: 480px to 767px
- Small Mobile: Below 480px

## 💻 How to Use

1. Download the files or clone the repository
2. Open `index.html` in any web browser
3. No server setup or dependencies required

## 📝 Customization

### Edit Content
- Open `index.html` and modify text in each section

### Change Colors
- Edit CSS variables in `styles.css`

### Update Contact Info
- Modify email, phone, and address in the contact section

### Add Social Media
- Add links in the footer or navigation
